# React-Projects

A collection of beginner & intermediate **React.js mini-projects** demonstrating different UI functionalities, component usage, and simple app logic.

This repository contains small React applications built to learn and practice React fundamentals such as component creation, state management, props, conditional rendering, forms, API calls, and routing.

---

## 📦 Projects Included

| Folder | Description |
|--------|-------------|
| **Birthday_Wish_Card** | UI to create and send a birthday wish card |
| **GithubInfoCard** | Search a GitHub username and display basic info using GitHub API |
| **OTP_LOGIN** | OTP based login UI with basic form and verification screen |
| **OTP_LOGIN_2** | Alternative OTP login design |
| **ParagraphGenerator** | Generate paragraphs of text given inputs |
| **ProfileComponent** | Simple profile UI component demo |

## 🛠 Getting Started

### Requirements

Make sure you have the following installed:

- Node.js (v14+ recommended)
- npm (comes with Node)

---

### 📥 Installation

1. **Clone the repository**

```bash
git clone https://github.com/uday246r/React-Projects.git
cd React-Projects
````

2. **Choose a project folder and install dependencies**

```bash
cd <PROJECT_FOLDER>
npm install
```

3. **Run the app**

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

🚀 Each project has its own `package.json`, so repeat install + start for each one.
